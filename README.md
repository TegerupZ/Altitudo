# Altitudo AB website

A responsive, Swedish-language static landing page for Altitudo AB.

## Files
- `index.html`: page structure and editable text
- `styles.css`: visual design and mobile layout
- `script.js`: mobile navigation and automatic copyright year

## Preview
Open `index.html` in a browser.

## Publish on GitHub Pages
In the GitHub repository, navigate to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`. Save. Note that availability of GitHub Pages for a private repository depends on your GitHub plan; if necessary, switch visibility deliberately or use another host.

## Content review before launch
This is a first-draft concept. Confirm the company's actual activities, brand positioning, logo, approved contact details and legal/privacy requirements before publishing. The text deliberately avoids unverified service and business claims. The site does not collect personal data or use analytics; it loads Google Fonts.
